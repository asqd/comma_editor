# CommaEditor

Быстрый редактор CSV, который не портит файлы: после сохранения файл отличается от исходного
только тем, что изменил пользователь. Ядро написано на Rust. Приложение для macOS — нативное,
на Swift/AppKit; для Windows, Linux и как вторая версия для macOS (CommaEditor W) — приложение
на Tauri поверх того же ядра.

## Сборка

Нужны Rust (1.88+), Xcode 16+ и XcodeGen (`brew install xcodegen`).

```bash
make test     # тесты ядра
make run      # собрать ядро, сгенерировать Xcode-проект, собрать и запустить приложение
make release  # универсальная Release-сборка и DMG (подпись и нотаризация — docs/RELEASE.md)
make icon     # перерисовать иконки из design/make-icon.swift (и с буквой W для Tauri-версии)
```

Для универсальной сборки нужен ещё Rust-таргет для Intel: `rustup target add x86_64-apple-darwin`.

После `make xcodeproj` проект можно открыть в Xcode: `apps/macos/CommaEditor.xcodeproj`.
При каждой сборке Xcode сам пересобирает ядро.

Приложение на Tauri (`apps/desktop`) собирается на Windows, Linux и macOS; на macOS оно
называется «CommaEditor W», чтобы стоять рядом с нативным. Нужны Rust, Node 22
(`apps/desktop/.nvmrc`) и, на Linux, WebKitGTK 4.1 (`libwebkit2gtk-4.1-dev`):

```bash
make desktop        # запустить с перезагрузкой при правках
make desktop-build  # Release-сборка: apps/desktop/src-tauri/target/release/commaeditor
make desktop-release  # установщики для этой системы в build/desktop: DMG, NSIS, AppImage и .deb
commaeditor --bench table.csv   # замер прокрутки: открыть, прокрутить, вывести время, выйти
COMMA_LOG=1 commaeditor a.csv   # команды окон в stderr; ошибки интерфейса пишутся туда всегда
```

Интерфейс можно открыть и в браузере, с настоящим ядром: мост для разработки отдаёт команды
приложения по HTTP (только с этой машины и только через прокси Vite).

```bash
cargo run --manifest-path apps/desktop/src-tauri/Cargo.toml --features bridge --bin comma-bridge
cd apps/desktop && npm run dev   # затем http://localhost:1430/?open=/путь/к/файлу.csv&lang=ru
```

Утилита командной строки:

```bash
cargo run -p comma-cli -- info samples/*.csv
cargo run -p comma-cli -- check samples/*.csv
cargo run -p comma-cli -- info book.xlsx   # листы книги Excel: размер, формулы, время чтения
cargo run --release -p comma-cli -- bench  # первый экран, чтение, сортировка и фильтр на 1, 12 и 60 млн строк
cargo run --release -p comma-cli -- generate 60m big.csv  # таблица для проверки больших файлов
```

## Как устроено сохранение без лишнего диффа

Исходные байты файла остаются в памяти. Документ хранит не таблицу строк, а список записей:

- нетронутая запись — это диапазон байтов исходного файла;
- изменённая запись — список полей, где нетронутые поля по-прежнему ссылаются на исходные байты
  (вместе с кавычками), а новые значения хранятся как текст.

При сохранении нетронутые записи и поля копируются побайтово. Новые значения кодируются в
кодировку файла и берутся в кавычки по правилам этого файла. У каждой записи сохраняется свой
перевод строки, BOM и наличие финального перевода строки тоже сохраняются. Undo и redo — это
обратимые замены диапазонов записей.

Гарантию «открыл и сохранил без правок — получил тот же файл» проверяют тесты, в том числе на
20 000 случайных входах.

## Что есть в версии 0.1

- Определение кодировки (UTF-8 с BOM и без, UTF-16LE/BE, Windows-1251, KOI8-R, Windows-1252),
  разделителя (`,` `;` табуляция `|`), переводов строк, стиля кавычек и строки заголовка.
- Многострочные значения, кавычки в кавычках, строки разной длины, незакрытые кавычки.
- Приложение для macOS на NSDocument: открытие, сохранение, автосохранение, версии, вкладки,
  недавние файлы, песочница.
- Сетка с ленивой подгрузкой строк: файл на миллион строк (88 МБ) открывается примерно за 0,1 с.
- Правка ячеек: двойной клик, Return или ввод с клавиатуры. Многострочные значения правятся
  в отдельном окне. Вставка и удаление строк и колонок, переименование колонок, undo/redo,
  копирование строк в формате TSV.
- Курсор ячейки: стрелки, Tab, Return, Delete.
- Интерфейс на русском и английском.

## Версия 0.2: поиск, сортировка и фильтры

Сортировка и фильтры — это представление: они меняют только то, что показано, а не файл.
Колонка номеров показывает номер строки в файле.

- Сортировка: клик по заголовку колонки (по возрастанию → по убыванию → порядок файла),
  Shift-клик добавляет следующий ключ. Тип колонки определяется сам: числа (`1 250,50`,
  `1,250.50`, `12%`), даты `ДД.ММ.ГГГГ`, текст в «естественном» порядке (`file2` < `file10`,
  без учёта регистра, ё как е). Пустые значения всегда в конце.
  «Таблица ▸ Упорядочить строки в файле» переносит порядок в файл одним отменяемым шагом.
- Фильтры (⇧⌘L): условия по колонке или по любой колонке, через И — содержит, равно,
  начинается с, заканчивается на, regex, больше и меньше (числа и даты), пусто, а также их
  отрицания. В контекстном меню ячейки: «Показать только „X“» и «Скрыть „X“».
- Поиск (⌘F, ⌘G, ⇧⌘G) и замена (⌥⌘F) по видимым строкам: с учётом регистра или без,
  ячейка целиком, регулярные выражения с группами `$1` в замене, поиск в одной колонке.
  «Заменить все» — один шаг отмены.

На миллионе строк сортировка занимает 0,2–0,6 с, фильтр по колонке 0,1 с, «Заменить все» 0,6 с.

Для проверки интерфейса из командной строки отладочная сборка понимает переменную
`COMMA_DEBUG_SCRIPT` (см. `Grid/DebugScript.swift`), например:

```bash
cp samples/people.csv /tmp/try.csv   # шаги правят документ, а автосохранение пишет в файл
open -n --env "COMMA_DEBUG_SCRIPT=sort=5:d;filter=3:equals:London;find=London" \
  -a build/DerivedData/Build/Products/Debug/CommaEditor.app /tmp/try.csv \
  --args -ApplePersistenceIgnoreState YES
```

## Версия 0.3: форматы сохранения

- «Сохранить как…» показывает кодировку (UTF-8 с BOM и без, UTF-16, Windows-1251, KOI8-R,
  Windows-1252), разделитель и переводы строк; выбранный формат становится форматом документа.
- «Экспортировать…» пишет копию в другом формате, документ остаётся прежним.
- «Экспортировать для Excel…» (⇧⌘E): UTF-8 с BOM, CRLF и разделитель, который ждёт Excel при
  текущих региональных настройках (`;` там, где десятичная запятая).
- В исходном формате файл по-прежнему пишется побайтово. При смене кодировки или переводов строк
  у записей сохраняются исходные кавычки; при смене разделителя значения заново берутся в кавычки
  там, где это нужно. Символы, которых нет в выбранной кодировке, дают понятную ошибку с номером
  строки и колонки.

## Версия 0.4: диапазоны ячеек

- Выделение прямоугольника: протягивание мышью, Shift-клик, Shift + стрелки, ⌘ + стрелки
  к краю таблицы, Page Up/Down; клик и протягивание по номерам строк выделяют строки целиком,
  ⌘A — всю таблицу, Escape сворачивает выделение до активной ячейки.
- ⌘C, ⌘X, ⌘V совместимы с Excel, Numbers и Google Sheets (табличный текст с кавычками
  для значений с табуляцией и переносами). Вставка начинается с левого верхнего угла
  выделения и при необходимости добавляет строки и колонки; одно скопированное значение
  заполняет всё выделение.
- ⌘D заполняет вниз, Delete очищает выделенные ячейки. Каждая операция — один шаг отмены.
- В строке состояния: размер выделения, сумма и среднее чисел в нём.

## Версия 0.5: операции над колонками

Меню «Данные». Команды работают с выделением, а если выделена одна ячейка — со всей колонкой
(по видимым строкам). Каждая операция — один шаг отмены.

- Текст: убрать пробелы по краям, убрать лишние пробелы, ВЕРХНИЙ и нижний регистр,
  Каждое Слово С Заглавной.
- Заполнить пустые ячейки значением сверху (для выгрузок со «сгруппированными» колонками)
  или заданным значением.
- Разделить колонку по строке или регулярному выражению (пусто — по пробелам): части уходят
  в новые колонки справа, исходная остаётся; с заголовком новые колонки называются «Имя 1»,
  «Имя 2»…
- Объединить выделенные колонки в новую через разделитель, пустые значения пропускаются.
- Удалить повторяющиеся строки: по всем колонкам или по выделенным, с учётом или без учёта
  регистра и пробелов; остаётся первая строка из одинаковых.

## Версия 0.6: экспорт

Экспорт берёт показанные строки: сортировка и фильтры определяют, что и в каком порядке
попадёт в файл.

- «Файл ▸ Экспортировать как»: JSON (массив объектов по именам колонок), Markdown, HTML
  (страница с таблицей), SQL (`CREATE TABLE` и `INSERT` на строку) и книга Excel (XLSX,
  с закреплённой строкой заголовка и шириной колонок по содержимому).
- «Правка ▸ Скопировать как»: Markdown, JSON, HTML, SQL для выделения или, если выделена одна
  ячейка, для всей таблицы.
- Числа экспортируются числами только в колонках, где все значения — числа без ведущих нулей
  и не длиннее 15 цифр: коды вроде `007` и номера карт остаются текстом. В XLSX числами
  становятся и значения вида `1 250,50`.
- Миллион строк: JSON около 1 с, Markdown и SQL около 2 с, XLSX около 7 с; файл собирается
  в фоне.

## Версия 0.7: панель инструментов

- Панель в заголовке окна: вставить строку и колонку, удалить строки, сортировка (меню),
  фильтр, «Данные» и «Экспорт» (меню), поиск. Иконки сортировки и фильтра заливаются, когда

- Поиск на панели ищет по мере ввода, Return и ⇧Return переходят по совпадениям, их число

  добавляет условие для этой колонки. У отсортированных и отфильтрованных колонок иконки
  видны всегда.

## Версия 0.8: профиль колонки

Панель справа (⌥⌘P или кнопка на панели инструментов) показывает активную колонку по видимым
строкам:

- тип: числа, целые числа, даты (`2024-01-31`, `31.01.2024`, с временем или без), да/нет, текст;
  тип колонки — тот, что у 80% непустых значений;
- сколько значений, пустых и уникальных; для чисел минимум, максимум, среднее и медиана,
  для дат самая ранняя и самая поздняя, для текста длина;
- гистограмма распределения чисел и дат;
- проблемы: значения не того типа («n/a» среди чисел) и пробелы по краям. Такие ячейки
  подсвечиваются в таблице, «Показать» переходит к следующей, «Убрать» чистит пробелы
  во всей колонке;
- десять частых значений, клик показывает только строки с этим значением.

Профиль миллиона строк считается за 0,15–0,55 с, в фоне.

## Версия 0.9: ремонт файла

Битые строки не мешают открыть файл и не теряются молча. После открытия и после каждой правки
ядро в фоне ищет проблемы (миллион строк — около 65 мс). Если они есть, справа открывается
панель «Ремонт файла» (⌥⌘R, кнопка на панели инструментов или в строке состояния), а номера
проблемных строк подсвечиваются.

- Ожидаемое число полей — то, что встречается в большинстве строк.
- Незакрытая кавычка: значение не закрывается, и весь хвост файла попал в одну ячейку.
- Лишняя кавычка: кавычка склеила несколько полей или строк в одно значение. Определяется
  так: если читать её как обычный символ, строки получают ожидаемое число полей.
- Не хватает полей: перенос строки внутри значения без кавычек, пустая строка, обрезанная строка.
- Лишние поля: разделитель внутри значения без кавычек (`Smith, John`, `12,5`) или пустые поля в конце.

Для выбранной строки панель показывает её текст в файле и варианты исправления с превью
результата; рекомендуемый вариант идёт первым:

- оставить кавычку как символ или удалить её — проглоченные строки снова становятся строками;
- склеить со следующей строкой (значение получает перенос строки и берётся в кавычки);
- дополнить пустыми полями, удалить пустые поля в конце, удалить строку;
- объединить лишние поля в колонке. Колонка выбирается по тому, насколько типичны значения
  для своих колонок: `12,5` попадёт в колонку сумм, а `Smith, John` — в колонку имён.

«Исправить все» применяет рекомендуемое исправление ко всем строкам одного вида одним шагом
отмены. Нетронутые строки по-прежнему пишутся побайтово; исправленные — по правилам CSV.

## Версия 0.10: карточка записи

Для широких таблиц, которые не помещаются в экран. «Вид ▸ Показать карточку записи» (⌥⌘I)
или кнопка на панели инструментов открывает справа текущую строку в виде формы: имя колонки
слева, значение справа.

- Карточка следует за курсором таблицы; ⌘[ и ⌘] (или стрелки в карточке) листают записи.
- Значения правятся прямо в карточке: Return или переход в другое поле сохраняет, Escape
  отменяет. Каждая правка — шаг отмены, как в таблице. Текст, набранный перед переходом
  к другой записи, сохраняется в той строке, где его набрали.
- Поле активной колонки подсвечено, клик по имени поля переводит курсор таблицы в эту колонку.
- «Найти поле» отбирает поля по имени или значению, «Скрыть пустые» убирает пустые.
- Правая панель общая: профиль колонки, ремонт файла и карточка сменяют друг друга.

## Версия 0.11: вид таблицы

- Номера строк больше не уезжают при прокрутке вбок. «Вид ▸ Закрепить колонки до этой»
  (или меню заголовка) оставляет слева колонки до текущей; «Снять закрепление» возвращает
  обычный вид. Таблица рисуется двумя синхронными таблицами: закреплённой и прокручиваемой.
- Автоширина: двойной клик по границе заголовка подгоняет колонку под содержимое;
  «Подогнать ширину колонок» (⌥⌘0) — выделенные колонки или все. Учитываются заголовок,
  первые 300 строк и строки на экране.
- Скрытие колонок: «Скрыть колонку» для выделенных колонок, «Показать все колонки».
  Файл не меняется; стрелки перескакивают скрытые колонки, число скрытых видно в строке состояния.
- Перенос текста: «Вид ▸ Перенос текста» — в одну строку, до 2, 3 или 5 строк в ячейке.
- Перемещение строк: перетащить номера выделенных строк (линия показывает, куда они встанут)
  или ⌃⌘↑ и ⌃⌘↓. Пока строки отсортированы, перемещать нельзя: порядок задаёт сортировка.
- Перемещение колонок: перетащить заголовок или ⌃⌘← и ⌃⌘→. Колонка переезжает в файле
  вместе с шириной. Каждое перемещение — один шаг отмены.

## Версия 0.12: невидимые символы

«Вид ▸ Показывать невидимые символы» (⇧⌘I) отмечает то, что обычно не видно, но ломает
сравнение, поиск и импорт:

- пробелы в начале и в конце значения — `·`, табуляция — `→`, неразрывный пробел — `°`,
  символы нулевой ширины и BOM внутри значения — `¦` (все отметки выделены оранжевым);
- перевод строки внутри значения — `↵`;
- пустое значение — бледный `∅`, а ячейка, которой в строке нет вовсе (строка короче остальных
  или пустая строка файла), закрашена серым.

Отметки только для показа: при правке ячейки редактор получает настоящее значение,
и в файл отметки не попадают.

## Версия 0.13: вычисляемая колонка

«Данные ▸ Вычисляемая колонка…» (⌥⌘=) добавляет справа от текущей колонку, посчитанную по
формуле, или заменяет значения текущей колонки (в формуле можно ссылаться на неё саму:
`{price} * 1.2`). Предпросмотр показывает результат на первых строках по мере ввода.

- Колонки — в фигурных скобках: `{price}` по имени из заголовка, `{B}` по букве, `{#2}` по номеру.
- Текст — в кавычках (`"кг"`, кавычка внутри удваивается), `&` склеивает текст.
- `+ - * / %` считают, `= <> < > <= >=` сравнивают (числа как числа, даты как даты, текст без
  учёта регистра), `AND`, `OR`, `NOT` объединяют условия.
- Функции: `IF`, `ROUND`, `ABS`, `MIN`, `MAX`, `SUM`, `LEN`, `UPPER`, `LOWER`, `TRIM`, `LEFT`,
  `RIGHT`, `MID`, `REPLACE`, `CONTAINS`, `CONCAT`, `COALESCE`, `ISEMPTY`, `YEAR`, `MONTH`, `DAY`,
  `DAYS`. Аргументы разделяются запятой или точкой с запятой.
- Числа читаются так, как их пишут люди (`1 250,50`), пустое значение считается нулём. Если в
  данных десятичная запятая, результат тоже пишется с запятой; лишние знаки после запятой
  отбрасываются (`0.1 + 0.2` даёт `0.3`).
- В CSV нельзя сохранить формулу, поэтому колонка заполняется готовыми значениями одним шагом
  отмены. Строки, где формула не сработала (не число, не дата, деление на ноль), остаются
  пустыми, и приложение говорит, сколько их и в какой строке первая.

Миллион строк: новая колонка около 0,5 с, замена значений около 0,3 с.

## Версия 0.14: кодировки

- Определение кодировки и разделителя теперь знает, уверено ли оно: BOM и правильный UTF-8 —
  да, UTF-8 с битыми байтами — нет, однобайтовая кодировка — когда частоты букв однозначны,
  разделитель — когда почти все строки делятся на одинаковое число полей.
- Если определение не уверено, при открытии появляется окно «Проверьте кодировку и разделитель»
  с выбором и предпросмотром начала файла. Его же открывает «Файл ▸ Проверить кодировку
  и разделитель…».
- «Файл ▸ Открыть заново в кодировке» и «…с разделителем»: UTF-8, UTF-16LE/BE, Windows-1251,
  KOI8-R, Windows-1252; запятая, точка с запятой, табуляция, вертикальная черта. Выбор
  запоминается для «Вернуть к сохранённому»; файл по-прежнему сохраняется побайтово в выбранной
  кодировке.
- Кракозябры: значения, которые когда-то прочитали не в той кодировке и так сохранили
  («РџСЂРёРІРµС‚», «ÐŸÑ€Ð¸Ð²ÐµÑ‚», «Ã©tÃ©», «Ïðèâåò»), находятся в первых строках

  кракозябры» (для выделения) возвращают текст одним шагом отмены. Исправление принимается,

## Версия 0.21: рецепты

- «Рецепты ▸ Начать запись»: дальше правки таблицы записываются как шаги, а в строке состояния
  видно «● Запись рецепта, шагов: N». «Остановить запись…» сохраняет рецепт под именем.
- Шаги называют колонки по заголовкам, поэтому рецепт находит их в следующей выгрузке, даже
  если колонки переставлены. Если во время записи был фильтр или сортировка, шаг запоминает
  их: «ВЕРХНИЙ РЕГИСТР: city (где country = «RU»)», «Удалить строки, где stock = «0»».

  колонок, сортировка файла, удаление строк по фильтру и исправление битых строк. Правки

- Рецепт применяется из меню «Рецепты» одним шагом отмены, на больших таблицах в фоне с ходом
  и отменой. Если в файле нет нужной колонки, рецепт останавливается, называет шаг и колонку
  и ничего не меняет.
- «Управление рецептами…»: список шагов словами, переименование, удаление шагов и рецептов,
  «Экспорт для Python…» — скрипт на pandas, который делает с файлом то же самое. Формулы
  переводятся в Python, где у функций есть близкий аналог; тест проверяет, что скрипт и
  рецепт дают один и тот же файл байт в байт.
- Рецепты хранятся файлами JSON в папке приложения (Application Support/CommaEditor/Recipes).

## Версия 0.25: формулы в книгах Excel

  формула получит `0,2501`.

  `ИНДЕКС`/`ПОИСКПОЗ`, `ПРОСМОТРX`, округление, текстовые функции и даты. Формулу с функцией,

- ⌘D протягивает формулу вниз со сдвигом ссылок, вставка `=…` из буфера создаёт формулы.
- В конец листа можно добавлять колонки, как и строки.

## Версия 0.26: строки и колонки в книгах

- В книгах Excel можно вставлять и удалять строки и колонки, в том числе на листах
  с формулами. Как в Excel, ссылки сдвигаются вместе с ячейками: в формулах всех листов,
  в объединённых ячейках, условном форматировании, проверке данных, гиперссылках,
  автофильтре и именованных диапазонах; ширины колонок переезжают вместе с ними. Формула,
  ссылавшаяся на удалённую ячейку, показывает `#REF!`.
- Одно ⌘Z отменяет вставку или удаление целиком, на всех листах сразу.
- Листы с таблицами Excel, рисунками, диаграммами и примечаниями, а также книги с
  диаграммами и сводными таблицами пока оставляют строки и колонки на месте: добавлять
  можно только в конец.

## Версия 0.27: режим «Таблица» и режим CSV

- Книга открывается в режиме «Таблица», как в Excel: столбцы подписаны A, B, C, первая
  строка — обычная строка с ячейками, номера строк совпадают с Excel.
- Переключатель «Таблица | CSV» справа от вкладок листов или «Вид ▸ Режим CSV» делает
  первую строку названиями столбцов, как в CSV-файле: по ним работают фильтр, поиск по
  колонке, карточка записи и экспорт в JSON, а сортировка оставляет первую строку
  наверху. Номера строк остаются номерами Excel. Режим общий для всех листов книги и
  файл не меняет.
- Лист, открытый впервые, показывается с первой строки, а не со второй.

## Версия 0.28: исправления после проверки

- Книги, которые записали программы (xlsxwriter, openpyxl, выгрузки), хранят вместо
  результатов нули и просят пересчитать формулы при открытии — теперь CommaEditor считает их
  сразу, как Excel. Книги, сохранённые Excel, показывают свои значения.
- Формулы массива (`{=SUM(B2:C2*B2:C2)}`) считаются по всему диапазону; ячейки в круговой
  ссылке показывают 0, как в Excel.
- Суммы с валютой и разделителями разрядов (`1 120,00 ₽`) сортируются и фильтруются как
  числа, в книгах и в CSV.
- «Экспортировать как ▸ XLSX» для листа книги, в том числе Excel 97–2003, пишет числа,
  проценты, даты и деньги с их форматами, без лишней строки букв.
- `=B2*1,5` вводится с десятичной запятой; ширины и скрытые колонки переезжают при вставке
  и удалении колонок и возвращаются по ⌘Z; «Исправить кракозябры» чинит и короткие слова;
  лист с несовпадающими тегами называется повреждённым, а не теряет строки молча.
- Формулы показываются так, как их пишет русский Excel: `=ОКРУГЛ(A1;2)+0,5`; вставка
  ошибочной формулы отклоняется с тем же сообщением, что и при наборе.
- Правый щелчок по ячейке открывает её меню («Показать только», «Скрыть»), а не меню текста;
  строки, перетащенные за номера, встают на место синей линии; «Скопировать как ▸ HTML»
  вставляется в Заметки, Pages и TextEdit по-русски; после выбора колонки или функции в
  вычисляемой колонке набор продолжается в поле формулы.
- Сравнение с книгой сразу берёт лист с тем же именем; «Вернуться к сохранённому» остаётся
  на открытом листе.

## Версия 0.29: закрепление строк

- «Вид ▸ Закрепить строки до этой» (и в меню ячейки) оставляет верхние строки на месте,
  пока таблица прокручивается вверх и вниз; «Снять закрепление строк» возвращает обычный вид.
  Строки и колонки можно закрепить вместе. Закреплённые строки правятся, выделяются и
  переносятся по строкам так же, как остальные.
- Книги Excel открываются с закреплёнными строками, как их закрепил Excel. В режиме CSV
  первая строка и так стоит в заголовках колонок, поэтому закреплённых строк на одну меньше.
- Версия приложения — 0.29.0, как в плане: прежняя 0.6.0 не менялась с подготовки к выпуску.

## Версия 0.30: введённое значение в формате ячейки

- Значение, введённое в ячейку книги, сразу показывается в её формате: `300` в денежной
  ячейке — «300,00 ₽», `2026-10-01` в ячейке с датой — «01.10.2026», `истина` — «ИСТИНА».
  В файл попадает то, что введено: `1250,555` показывается «1 250,56 ₽», а сохраняется
  1250.555. При правке ячейки в редакторе — введённый текст.
- Процентная ячейка принимает число без знака процента, как Excel: `10` и `0,1` — это 10 %.

## Версия 0.31: оформление новых строк и мелочи книг

- Вставленная строка берёт оформление строки выше, а вставленная колонка — колонки слева,
  как в Excel: `300` в новой строке денежной таблицы сразу «300,00 ₽», и в файле у ячейки
  тот же стиль. Колонки, добавленные правее данных, остаются без оформления.
- Формула с датой в ячейке «Общий» показывает дату, как в Excel: `=СЕГОДНЯ()` — «12.10.2026»,
  `=ТДАТА()` — с временем, `=A1+7` от ячейки с датой — тоже дата. В книгу добавляется стиль
  с форматом даты, сделанный из стиля ячейки, так что шрифт и заливка сохраняются.
- Скрытые ячейки объединённой области не принимают значений: набор в такой ячейке правит
  первую ячейку области, а вставка в неё отклоняется с подсказкой, куда вводить.
- Новые кодировки: Windows-1250, 1253 (греческая), 1254, 1257, KOI8-U и DOS CP866; русские
  файлы в CP866 определяются сами.
- ⇧⌘S в окне книги — «Сохранить как…»; в любой раскладке.

## Версия 0.32: книги Excel в глубину

- Формулы с именованными диапазонами (`=Итого_сумма`, `=SUM(Суммы)`), формулы массивов
  и структурированные ссылки на таблицы (`[@Цена]*[@Кол]`, `=SUM(Заказы[Сумма])`)
  вычисляются сразу, а не ждут Excel.
- Строки листов с формулами можно перетаскивать и сортировать в файл, как в Excel:
  перемещение работает как «вырезать и вставить», ссылки идут за строками; сортировка
  уносит значения, формулы и ссылки, а оформление остаётся на месте.
- Вставка и удаление строк и колонок работают на листах с таблицами Excel, рисунками,
  фигурами, примечаниями и диаграммами и в книгах со сводными таблицами. Таблица растёт
  со вставленными в неё строками и заполняет их вычисляемыми колонками; примечания идут
  за своими ячейками, рисунки и фигуры — за ячейками под углами, ряды диаграмм и источники
  сводных — за своими диапазонами. Закреплённым остаётся только лист, на котором лежит
  сводная таблица.
- Пересчёт после правки трогает только то, что изменилось с прошлого раза: правка одной
  строки листа с 300 тыс. формул — 75 мс вместо 580.
- Большой лист сохраняется потоком: XML листа сжимается по мере записи, архив пишется
  прямо в файл. Пик памяти при сохранении листа на 1 млн строк — 685 МБ вместо 1,2 ГБ.
- Большие книги открываются в несколько раз быстрее: лист читается на всех ядрах, пока
  распаковывается. Лист на 1 млн строк — 0,15 с вместо 1,3; книга готова к показу через
  0,2 с после открытия.
- Строка итогов таблицы Excel (`ПРОМЕЖУТОЧНЫЕ.ИТОГИ`, `SUBTOTAL`) считается сразу.
- Отказ вставить, удалить или переместить строки объясняет причину: сводная таблица на
  листе, таблица Excel или объединённые ячейки. «Вставить строку выше» и «Вставить колонку
  слева» снова доступны в книгах.

## Версия 1.0: первый выпуск

Выпуск для прямого скачивания: DMG без подписи Apple Developer, как его открыть — на сайте
в разделе «Установка» и в `docs/RELEASE.md`. Версия приложения — 1.0.0 (сборка 4).


- Сортировка в файл переносит оформление вместе со значениями, как в Excel: дата или заливка
  уходит со своей строкой, а не остаётся на месте.
- На листах с таблицами Excel строки перемещаются и сортируются, если остаются среди данных
  своей таблицы или вне таблиц. Колонку можно вставить в таблицу — она станет её колонкой
  «Столбец1», — и удалить, если её не читают формулы.
- На листах с формулами колонки перемещаются, делятся и объединяются, ссылки на всех листах
  идут следом. Отказ объясняет, что мешает: сводная таблица, таблица Excel или объединённые
  ячейки.
- Формула, читающая строку таблицы, показывается как в Excel — `[@Цена]`, — а в файл пишется
  так, как его понимает Excel.
- Короткие значения ячеек хранятся без отдельного выделения памяти: лист на 1 млн строк
  занимает 335 МБ вместо 425.
- VoiceOver называет сортировку и фильтр колонок, кнопки-стрелки карточки, статистику
  профиля, списки в окнах сохранения и сравнения, в панелях поиска и фильтра.
- Сайт: скриншоты, раздел «Установка» для неподписанного приложения, страница
  конфиденциальности. Выпуск — DMG с подписью ad-hoc для прямого скачивания.

## Версия 1.1: Windows, Linux и CommaEditor W

CommaEditor появился на Windows и Linux. Это отдельное приложение на Tauri 2 с тем же ядром
на Rust; на Mac оно ставится рядом с нативным под именем CommaEditor W, с буквой W на иконке.
Версия всех сборок 1.1.0 (сборка 5 для macOS).

- Всё, что умеет нативная версия, кроме превью в Finder, автосохранения с версиями и песочницы:
  поиск и замена, сортировка и фильтры, данные и экспорт, профиль колонки, ремонт файла,
  карточка записи, вид таблицы, вычисляемая колонка, сравнение файлов, рецепты и книги Excel
  с формулами.
- Таблица рисуется на canvas и прокручивается без рывков на 60 млн строк.
- Сохранение явное; после сбоя несохранённые правки предлагается восстановить.
- Рецепты на Mac общие у обеих версий.
- Установщики: NSIS для Windows x64 и ARM64, AppImage и `.deb` для Linux x86_64 и ARM64,
  Flatpak для x86_64, универсальный DMG для Mac. Подписей Microsoft и Apple нет, как их
  открыть, написано на сайте и в `docs/RELEASE.md`.
- Один номер версии у всех сборок: `scripts/version.sh`, CI проверяет, что он совпадает.
