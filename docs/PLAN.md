# План CommaEditor

Рабочий план разработки. Требования и обоснование фич — в документе
[SimpleCSVEditor](https://claude.ai/code/artifact/7b671fe1-9a70-4b1c-aaf0-fda5502aa966).
Что вошло в каждую версию — в README. После каждого шага отмечаем сделанное здесь.

Архитектура: ядро на Rust (`core/`), приложение для macOS на Swift/AppKit (`apps/macos/`),
Windows и Linux позже на Tauri поверх того же ядра. Сначала macOS.

## Ближайшие шаги

Порядок предлагаемый, его можно менять.

1. [x] **Режим ремонта.** Готово в 0.9: подсветка номеров строк, панель с вариантами
   исправления и превью, «Исправить все» по видам проблем.
2. [x] **Карточка записи.** Готово в 0.10: форма справа, следует за курсором, ⌘[ и ⌘],
   правка полей, поиск поля, скрытие пустых.
3. [x] **Вид таблицы.** Готово в 0.11: закрепление колонок и номеров строк, автоширина,
   скрытие колонок, перенос текста, перемещение строк и колонок мышью и с клавиатуры.
4. [x] **Невидимые символы.** Готово в 0.12: режим ⇧⌘I, отметки только для показа.
5. [x] **Вычисляемая колонка.** Готово в 0.13: формулы в ядре, окно с предпросмотром,
   новая колонка или замена значений текущей.
6. [x] **Кодировка.** Готово в 0.14: окно проверки при неуверенном определении,
   «Открыть заново в кодировке / с разделителем», исправление кракозябр.
   Дальше можно добавить другие кодировки (ISO-8859-x, Windows-1250/1253…, Mac Roman).
7. [x] **Поиск внутри выделения.** Готово в 0.15.
8. [x] **Quick Look.** Готово в 0.16 для TSV и других файлов с разделителями; для `.csv`
   macOS оставляет свой просмотр.
