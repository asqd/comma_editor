# План CommaEditor

Рабочий план разработки. Требования и обоснование фич — в документе
[SimpleCSVEditor](https://claude.ai/code/artifact/7b671fe1-9a70-4b1c-aaf0-fda5502aa966).
Что вошло в каждую версию — в README. После каждого шага отмечаем сделанное здесь.

Архитектура: ядро на Rust (`core/`), приложение для macOS на Swift/AppKit (`apps/macos/`),
Windows и Linux позже на Tauri поверх того же ядра. Сначала macOS.

## Ближайшие шаги

Порядок предлагаемый, его можно менять.

1. [ ] **Режим ремонта.** Строки с неправильным числом колонок и незакрытые кавычки:
   подсветка в сетке, список проблемных строк, варианты исправления (дополнить пустыми,
   склеить перенесённые строки, закрыть кавычку). Сейчас такие строки открываются, но никак
   не отмечены.
2. [ ] **Карточка записи.** Строка показывается вертикально, как форма; стрелки листают
   записи; правка полей прямо в карточке.
3. [ ] **Вид таблицы.** Закрепление первых N колонок, автоширина по содержимому (двойной клик
   по границе), перенос текста, скрытие колонок, перетаскивание строк и колонок.
4. [ ] **Невидимые символы.** Пробелы по краям, табы, NBSP; пустая ячейка отличается
   от пустой строки.
5. [ ] **Вычисляемая колонка** по простому выражению (`{price} * {qty}`, конкатенация,
   условие).
6. [ ] **Кодировка.** Диалог открытия с превью, когда автоопределение не уверено;
   «Открыть заново в кодировке…»; исправление кракозябр в уже прочитанном тексте.
7. [ ] **Поиск внутри выделения**, а не только в колонке или во всей таблице.
8. [ ] **Quick Look:** превью CSV таблицей в Finder (расширение приложения).
