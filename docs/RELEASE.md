# Выпуск CommaEditor

Один выпуск — один тег `v<версия>` и одна страница на GitHub: на ней DMG нативного приложения
для macOS и установщики Tauri-версии для Windows, Linux и macOS (CommaEditor W). Номер версии
общий для всех сборок:

```bash
scripts/version.sh          # показать версию; ошибка, если файлы расходятся (CI это проверяет)
scripts/version.sh 1.1.0    # поставить версию ядру, приложению для macOS и Tauri-версии
```

`scripts/version.sh` меняет `workspace.package.version` в `Cargo.toml`, `MARKETING_VERSION` в
`apps/macos/project.yml`, версию в `apps/desktop/src-tauri/Cargo.toml` и `package.json` и
добавляет выпуск в метаданные для Linux. `CURRENT_PROJECT_VERSION` (номер сборки для macOS)
поднимается руками.

## Порядок выпуска

1. `scripts/version.sh X.Y.Z`, поднять `CURRENT_PROJECT_VERSION`, обновить раздел версии в README.
2. Пройти ручную проверку: нативное приложение — ниже, Tauri-версия — в её разделе.
3. Коммит, тег `vX.Y.Z`, `git push --tags`. Процесс **Release** в GitHub Actions соберёт
   установщики Tauri-версии и положит их с суммами SHA-256 в черновик выпуска этого тега.
4. `make release` на Mac и `gh release upload vX.Y.Z build/release/CommaEditor-X.Y.Z.dmg*`.
5. В черновике: описание из README и суммы, затем «Publish release». Кнопки сайта ведут на
   `/releases/latest`.

# Нативное приложение для macOS

Сборка универсальная (Apple Silicon и Intel), macOS 14 и новее. Приложение работает в песочнице,
поэтому одна и та же сборка подходит и для прямого скачивания, и для Mac App Store.

## Локальная проверочная сборка

```bash
make release
```

Скрипт `scripts/release.sh` генерирует Xcode-проект, собирает Release-архив для обеих
архитектур, проверяет подпись и упаковывает приложение в `build/release/CommaEditor-<версия>.dmg`,
рядом — `.sha256` с контрольной суммой. Без сертификата подпись ad-hoc.

## Выпуск для прямого скачивания без аккаунта Apple Developer

Так CommaEditor распространяется сейчас: DMG с подписью ad-hoc, без нотаризации.

1. `make release`.
2. Создать выпуск на GitHub с тегом `v<версия>`, приложить DMG и `.sha256`, в описание —
   раздел версии из README и контрольную сумму.
3. Кнопка «Скачать» на сайте ведёт на `/releases/latest`.

macOS не открывает такое приложение молча. При первом запуске появляется «Файл «CommaEditor»
не был открыт. Apple не удалось подтвердить…» с кнопками «Переместить в Корзину» и «Готово».
Дальше:

- macOS 15 и новее: «Готово», затем «Системные настройки ▸ Конфиденциальность и безопасность»,
  внизу «Все равно открыть» у CommaEditor, подтвердить паролем. Кнопка видна около часа после
  попытки запуска.
- macOS 14: правый щелчок по приложению в «Программах» ▸ «Открыть» ▸ «Открыть».
- Любая версия, через Терминал: `xattr -dr com.apple.quarantine /Applications/CommaEditor.app`.

Это нужно один раз; обновления, скачанные заново, спрашивают снова. Расширение Quick Look
(TSV и другие разделители по пробелу в Finder) macOS подключает после первого запуска
приложения из «Программ»; копия вне установленного приложения его не даёт. Инструкция есть на сайте
в разделе «Установка». Проверить сборку как скачанную: поставить DMG атрибут карантина
(`xattr -w com.apple.quarantine "0083;$(printf %x $(date +%s));Safari;$(uuidgen)" файл.dmg`),
скопировать приложение из него и запустить — должно появиться окно выше; после
`xattr -dr com.apple.quarantine` приложение открывается.

## Выпуск для прямого скачивания с подписью (Developer ID), на будущее

Один раз:

1. Вступить в Apple Developer Program и узнать Team ID (developer.apple.com → Membership).
2. В Xcode → Settings → Accounts создать сертификат **Developer ID Application**.
   Проверка: `security find-identity -v -p codesigning` показывает «Developer ID Application».
3. Создать пароль приложения на appleid.apple.com и сохранить профиль для нотаризации:
   ```bash
   xcrun notarytool store-credentials commaeditor --apple-id you@example.com --team-id ABCDE12345
   ```

Каждый выпуск:

```bash
DEVELOPMENT_TEAM=ABCDE12345 NOTARY_PROFILE=commaeditor make release
```

Скрипт подпишет приложение и DMG с отметкой времени, отправит DMG на нотаризацию, дождётся
ответа, прикрепит результат (`stapler`) и проверит DMG через Gatekeeper (`spctl`).

## Выпуск в Mac App Store

1. В App Store Connect создать приложение с bundle ID `app.commaeditor.CommaEditor`
   (или поменять `PRODUCT_BUNDLE_IDENTIFIER` в `apps/macos/project.yml` на свой).
2. Нужны сертификаты **Apple Distribution** и **Mac Installer Distribution**, профиль Mac App Store.
3. `make xcodeproj`, открыть `apps/macos/CommaEditor.xcodeproj`, Product → Archive,
   в Organizer — Distribute App → App Store Connect.
4. Песочница, манифест приватности (`PrivacyInfo.xcprivacy`) и категория уже настроены.
   Для страницы в магазине нужны скриншоты, описание и ссылка на политику конфиденциальности:
   приложение не собирает данных и не ходит в сеть.

## Ручная проверка

Автотесты покрывают ядро. Интерфейс нужно пройти руками. Используйте копии файлов:
автосохранение пишет прямо в открытый файл.

Открытие и сохранение
- [ ] Двойной клик по `.csv` в Finder открывает файл; «Открыть недавние» работает.
- [ ] Файл в Windows-1251 с `;` и CRLF открывается по-русски; после правки одной ячейки
      `git diff` или `cmp` показывает изменение только в этой строке.
- [ ] «Сохранить как…» с другой кодировкой и разделителем; повторное открытие показывает те же данные.
- [ ] «Экспортировать для Excel…»: файл открывается в Excel без кракозябр и разбит по колонкам.
- [ ] Значение с эмодзи в файле Windows-1251: при сохранении понятная ошибка, файл не испорчен.

Правка
- [ ] Двойной клик, Return и ввод с клавиатуры начинают правку; Escape отменяет; Return переходит вниз.
- [ ] Многострочное значение открывается в отдельном окне, ⌘↩ сохраняет.
- [ ] Вставка и удаление строк и колонок, переименование колонки, ⌘Z и ⇧⌘Z.

Выделение и буфер обмена
- [ ] Протягивание мышью, Shift-клик, клик и протягивание по номерам строк, Shift и ⌘ со стрелками.
- [ ] ⌘C из CommaEditor и ⌘V в Excel или Numbers; обратно из Excel в CommaEditor, включая
      ячейки с переносами строк.
- [ ] ⌘D, Delete, ⌘X; одно скопированное значение заполняет выделение.

Панель инструментов
- [ ] Каждая кнопка панели работает; недоступные команды приглушены (например, удаление без выделения).
- [ ] «Настроить панель инструментов…»: перестановка, режим «Значки и текст», настройка сохраняется.
- [ ] Наведение на заголовок колонки показывает иконки; клик по фильтру добавляет условие для колонки.

Поиск, сортировка, фильтры
- [ ] Клик по заголовку сортирует (по возрастанию, по убыванию, порядок файла), Shift-клик добавляет ключ.
- [ ] Фильтр ⇧⌘L: ввод значения, добавление и удаление условий, «Готово» сбрасывает фильтр.
- [ ] Контекстное меню ячейки: «Показать только» и «Скрыть».
- [ ] ⌘F, ⌘G, ⇧⌘G; ⌥⌘F, «Заменить», «Заменить все», затем ⌘Z.
- [ ] Выделить диапазон и ⌥⌘F: выбрано «В выделении (N × M)», счётчик и «Заменить все» — только в нём.

Профиль колонки
- [ ] ⌥⌘P открывает панель; при переходе в другую колонку профиль обновляется.
- [ ] Проблемные ячейки подсвечены; «Показать» переходит по ним, «Убрать» чистит пробелы.
- [ ] Клик по частому значению включает фильтр.

Ремонт файла
- [ ] Файл со строками разной длины, пустой строкой и незакрытой кавычкой открывается,
      панель ремонта показывается сама, номера проблемных строк подсвечены.
- [ ] Выбор строки в панели переходит к ней в таблице; варианты показывают превью.
- [ ] Каждое исправление и «Исправить все» отменяются ⌘Z; после сохранения нетронутые строки
      не меняются (`git diff`).

Вид таблицы
- [ ] Закрепить колонки до третьей: при прокрутке вбок номера строк и три колонки на месте,
      вертикальная прокрутка колесом над любой частью двигает обе; выделение мышью через границу.
- [ ] Правка ячейки в закреплённой колонке; сортировка и фильтр по ней из заголовка.
- [ ] Двойной клик по границе заголовка подгоняет ширину; ⌥⌘0 для выделенных колонок.
- [ ] Скрыть колонку, стрелки её перескакивают, «Показать все колонки» возвращает.
- [ ] Перенос текста до 3 строк: длинные значения переносятся, номера строк выровнены по верху.
- [ ] Перетащить номера выделенных строк: синяя линия показывает место, строки встают туда; ⌘Z.
- [ ] Перетащить заголовок колонки: колонка переезжает в файле с шириной; ⌘Z.

Невидимые символы
- [ ] ⇧⌘I: пробелы по краям, табуляция, неразрывный пробел, пустые и отсутствующие поля видны.
- [ ] Правка ячейки с отметками в этом режиме: в редакторе настоящее значение; после Return
      без изменений файл не меняется (`git diff`).

Вычисляемая колонка
- [ ] ⌥⌘=: формула `{price} * {qty}` — предпросмотр сразу; ошибка в формуле видна под полем,
      кнопка неактивна; меню «Колонка» и «Функция» вставляют текст.
- [ ] «Добавить колонку» и «Заменить значения»; строки с ошибкой пустые, сообщение о них; ⌘Z.

Кодировки
- [ ] Файл с непонятной кодировкой (например, греческий в Windows-1253): окно проверки
      появляется само; смена кодировки и разделителя сразу меняет предпросмотр.
- [ ] «Файл ▸ Открыть заново в кодировке ▸ KOI8-R» для файла в Windows-1251: текст другой;
      «Определить автоматически» возвращает; при несохранённых правках сначала вопрос.
- [ ] Файл с кракозябрами в UTF-8: панель ремонта с примером, «Исправить во всём файле», ⌘Z.

Карточка записи
- [ ] ⌥⌘I на таблице с 50+ колонками: поля текущей строки, активное подсвечено.
- [ ] ⌘[ и ⌘] листают записи; набрать текст в поле и сразу нажать ⌘] — правка попала в прежнюю строку.
- [ ] Escape в поле возвращает значение; ⌘Z отменяет правку из карточки.

Данные и экспорт
- [ ] Меню «Данные»: каждая команда и её отмена.
- [ ] «Экспортировать как»: JSON, Markdown, HTML, SQL, XLSX; XLSX открывается в Excel и Numbers.
- [ ] «Скопировать как» Markdown и HTML вставляются в Заметки или Pages таблицей.

Сравнение файлов
- [ ] «Файл ▸ Сравнить с файлом…» на двух выгрузках одной таблицы: ключ выбран сам, видны
      удалённые (красный фон), новые (зелёный) и изменённые строки со значениями «было» и «стало».
- [ ] Флажки «Без учёта регистра» и «Без пробелов по краям» и смена ключа пересчитывают
      сравнение; «Отменить» в строке состояния прерывает долгое сравнение.
- [ ] Двойной щелчок по строке выделяет её в исходной таблице; «Открыть как таблицу» создаёт
      новый документ с колонкой «Сравнение».

Рецепты
- [ ] «Рецепты ▸ Начать запись», несколько правок колонок, фильтр и удаление строк, «Остановить
      запись…»: рецепт сохранён, в «Управлении рецептами» шаги описаны словами с условиями фильтра.
- [ ] ⌘Z во время записи уменьшает число шагов в строке состояния, повтор возвращает шаг.
- [ ] Рецепт из меню на другой выгрузке с переставленными колонками даёт ту же чистку; ⌘Z
      отменяет всё одним шагом; без нужной колонки — сообщение с номером шага и именем колонки.
- [ ] «Экспорт для Python…» сохраняет скрипт; `python3 скрипт.py` рядом с файлом даёт тот же результат.

Превью в Finder
- [ ] После установки приложения пробел на `.tsv` в Finder показывает таблицу с номерами строк
      и строкой «кодировка · разделитель»; файл в Windows-1251 читается по-русски.

Большие файлы
- [ ] Файл на миллион строк открывается за секунду и прокручивается плавно.
- [ ] Файл на 1–5 ГБ: таблица видна сразу, «Чтение файла: N %» растёт; правки и сортировка
      недоступны до конца чтения; затем сортировка идёт в фоне, «Отменить» её прерывает.
- [ ] На файле от 200 тыс. строк «Заменить все», «В верхний регистр» и вычисляемая колонка
      показывают ход в строке состояния; таблица листается; «Отменить» в строке состояния
      оставляет файл как был, а ⌘Z после законченной правки возвращает всё одним шагом.
- [ ] Пока такая правка идёт, другие правки и ⌘Z недоступны, а ⌘S сохраняет файл как был до неё.

# Tauri-версия: Windows, Linux и CommaEditor W для macOS

Приложение `apps/desktop` на Tauri 2. Установщики без платных сертификатов, без автообновления:
новая версия — по ссылке со страницы выпуска, она же в окне «О программе».

| Система | Файл | Как собирается |
|---|---|---|
| Windows 10 и 11, x64 | `CommaEditor-X.Y.Z-windows-x64-setup.exe` | NSIS, для текущего пользователя, без прав администратора; WebView2 скачивается, если его нет |
| Windows 11 на ARM | `CommaEditor-X.Y.Z-windows-arm64-setup.exe` | то же, собирается на x64 |
| Linux x86_64 | `CommaEditor-X.Y.Z-linux-x86_64.AppImage` | работает без установки |
| Ubuntu 22.04+, Debian 12 | `commaeditor_X.Y.Z_amd64.deb` | зависимости — WebKitGTK 4.1 и GTK 3 |
| Linux, Flatpak | `CommaEditor-X.Y.Z-linux-x86_64.flatpak` | из того же `.deb`, среда GNOME 47 с Flathub |
| macOS 10.15+, universal | `CommaEditor-W-X.Y.Z-macos-universal.dmg` | подпись ad-hoc, как у нативного DMG |

Рядом с каждым файлом — `.sha256`. Всё собирает процесс **Release**
(`.github/workflows/release.yml`) по тегу `v*`; при изменении упаковки он собирает установщики
на любой ветке, без выпуска, чтобы видеть, что они собираются. Под Linux на ARM готовых
установщиков пока нет: бесплатные ARM-машины GitHub есть только у открытых репозиториев.

## Локальная сборка

```bash
make desktop-release        # установщики для этой системы в build/desktop, с .sha256
TARGET=aarch64-pc-windows-msvc scripts/desktop-release.sh   # Windows на ARM, на x64
```

Нужны Rust, Node 22, на Windows — инструменты сборки Visual Studio (для ARM — компоненты ARM64),
на Linux — `libwebkit2gtk-4.1-dev libgtk-3-dev librsvg2-dev libxdo-dev libssl-dev patchelf file`.

## Установка без подписи

- **Windows.** SmartScreen показывает «Система Windows защитила ваш компьютер». «Подробнее» ▸
  «Выполнить в любом случае». Сумму проверяет `Get-FileHash .\CommaEditor-*-setup.exe` в
  PowerShell. Убрать предупреждение может только подпись кода (сертификат или сервис вроде
  Azure Trusted Signing); пока её нет, оно показывается для каждой новой версии.
- **Linux.** AppImage — `chmod +x` и запуск; `.deb` — `sudo apt install ./commaeditor_*.deb`;
  Flatpak — `flatpak install --user ./CommaEditor-*.flatpak` (нужен удалённый репозиторий
  Flathub для среды GNOME). Подписи пакетов не нужны.
- **macOS, CommaEditor W.** Тот же порядок, что для нативного DMG выше, но
  `xattr -dr com.apple.quarantine "/Applications/CommaEditor W.app"`.

Всё это есть на сайте в разделе «Windows, Linux и вторая версия для Mac».

## Flathub

Манифест — `apps/desktop/packaging/flatpak/app.commaeditor.Desktop.yml`, метаданные —
`apps/desktop/packaging/linux/app.commaeditor.Desktop.metainfo.xml`. Чтобы подать заявку на
Flathub, нужно:

- в манифесте заменить источник `commaeditor.deb` на ссылку на `.deb` со страницы выпуска и его
  `sha256` (Flathub собирает без доступа к сети, но качает объявленные источники);
- подтвердить домен `commaeditor.app` для идентификатора `app.commaeditor.Desktop` или взять
  `io.github.asqd.CommaEditor`;
- указать лицензию (`project_license`) и скриншоты в метаданных; Flathub требует открытый
  репозиторий с исходниками или явную лицензию на распространение;
- открыть запрос в `flathub/flathub` по их инструкции. Это делается руками, с вашего аккаунта.

## Ручная проверка Tauri-версии

Автотесты покрывают ядро и команды сеанса (`cargo test` в `apps/desktop/src-tauri`) на трёх
системах. Интерфейс проходится руками на Windows, на Linux (GNOME на Wayland и X11) и на
CommaEditor W на Mac. На копиях файлов.

Установка
- [ ] Установщик ставится без прав администратора; ярлык в меню «Пуск» или в списке приложений.
- [ ] `.csv`, `.tsv` и `.xlsx` открываются из Проводника или файлового менеджера через
      «Открыть с помощью»; второй файл открывается в новом окне того же приложения.
- [ ] Удаление через «Параметры ▸ Приложения» (Windows) или пакетный менеджер не оставляет
      привязок к файлам.
- [ ] На Mac: CommaEditor W стоит рядом с CommaEditor, иконка с W, у обоих свои окна и меню.

Окна и меню
- [ ] Меню в окне (Windows, Linux): Alt открывает меню, сочетания Ctrl как в подсказках; «Справка
