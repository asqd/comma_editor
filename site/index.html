Что умеет

      

        
          
ВозможностьЧто именноКлавиши

        
        
          

            1Кодировки и разделители
            UTF-8 с BOM и без, UTF-16, Windows-1251, KOI8-R, KOI8-U, DOS 866, Windows-1250, 1252, 1253, 1254, 1257. Разделитель: запятая, точка с запятой, табуляция или черта. Если кодировку не удаётся определить уверенно, программа спросит и покажет начало файла. Кракозябры вроде «РџСЂРёРІРµС‚» находит и исправляет.
            
          

          

            2Большие файлы
            Файлы от 64 МБ не загружаются в память целиком, первая страница появляется за сотые доли секунды. Чтение, поиск, профиль и экспорт используют все ядра процессора. Долгие правки идут в фоне, их можно прервать.
            
          

          

            3Ремонт файла
            Находит незакрытые и лишние кавычки, разделитель внутри значения, обрезанные строки и предлагает варианты исправления с превью. «Исправить все» отменяется одним ⌘Z.
            ⌥⌘R
          

          

            4Сортировка, фильтры, поиск
            Сортировка и фильтры меняют только то, что на экране, сам файл остаётся прежним. Числа вида 1 250,50 и даты сортируются правильно, file2 идёт раньше file10. Поиск и замена понимают регулярные выражения и работают по колонке или выделению.
            ⇧⌘L ⌥⌘F
          

          

            5Профиль колонки
            Тип данных, сколько пустых и уникальных значений, минимум, медиана, гистограмма и самые частые значения. Подсвечивает «n/a» среди чисел и лишние пробелы по краям.
            ⌥⌘P
          

          

            6Вычисляемая колонка
            Новая колонка по формуле: {price} * 1.2, IF, ROUND, функции для текста и дат. Результат на первых строках виден прямо во время ввода.
            ⌥⌘=
          

          

            7Сравнение двух файлов
            Строки сопоставляются по ключевой колонке или по номеру, колонки по заголовкам, даже если они стоят в другом порядке. Два файла по миллиону строк сравниваются за 0,17 с.
            ⌥⌘D
          

          

            8Рецепты
            Запишите правки один раз и повторяйте их на каждой новой выгрузке. Рецепт можно сохранить как скрипт на pandas, и он сделает с файлом то же самое, байт в байт.
            
          

          

            9Книги Excel
            .xlsx и .xlsm можно править, при сохранении меняются только тронутые ячейки. Формулы пересчитываются сразу, понимают имена и ссылки на таблицы, их можно писать по-русски: =СУММ(B2:B5). Если вставить, удалить, переместить или отсортировать строки, вместе с ними сдвинутся ссылки, таблицы, примечания, рисунки, диаграммы и сводные. .xls открываются для просмотра.
            
          

          

            10Экспорт
            JSON, Markdown, HTML, SQL и XLSX. Выгружается то, что на экране, с сортировкой и фильтрами. Коды вроде 007 остаются текстом и не теряют нули.
            ⇧⌘E
          

          

            11Невидимые символы
            Пробелы по краям ·, табуляция →, неразрывный пробел °, нулевая ширина ¦, перевод строки ↵, пустое ∅.
            ⇧⌘I
          

          

            12Quick Look и карточка записи
            По пробелу в Finder файл открывается таблицей, а не сплошным текстом. Широкую строку удобно читать и править в виде формы.
            ⌥⌘I

        Замерено на Apple M4 Pro, файл уже лежал в кэше системы. Считалось время ядра, без окна
        и отрисовки таблицы. В таблице 10 колонок, сортировка шла по колонке с суммами.
        Первый экран не зависит от размера, потому что сначала читаются только первые 32 МБ,
        а остальное дочитывается в фоне. Повторить замер можно командой
        cargo run --release -p comma-cli -- bench.
      

      

        Индекс занимает 16 байт на строку. Таблица на 12 млн строк прокручивается со скоростью
        120 кадров в секунду на экране 120 Гц. Книга Excel на миллион строк открывается за 0,2 с,
        а правка ячейки с пересчётом формул на 100 тыс. строк занимает десятые доли секунды.
        Приложение весит около 28 МБ.

Как устроено сохранение без лишнего диффа

      

        

          Программа держит в памяти исходные байты файла и хранит не таблицу строк,
          а список записей. Запись, которую не трогали, остаётся ссылкой на кусок исходного
          файла. Если в записи что-то поменяли, она становится списком полей: нетронутые поля
          по-прежнему ссылаются на исходные байты вместе с кавычками, а новые хранятся как текст.
        

        

          При сохранении всё нетронутое копируется как есть. Новые значения записываются
          в кодировке файла и берутся в кавычки так, как принято в этом файле. Перевод строки
          у каждой записи остаётся своим. Отмена и повтор просто меняют одни записи на другие.
        

      


      

      

        Тесты проверяют, что файл, открытый и сохранённый без правок, совпадает с исходным,
        в том числе на 20 000 случайных файлов. С книгами Excel так же: при сохранении
        переписываются только изменённые ячейки, а стили, диаграммы и макросы копируются без изменений.

Установка

      
    
        
  1. 
          Скачайте DMG со страницы выпуска,
          откройте его и перетащите CommaEditor в «Программы».
        
    2. 
        
  2. 
          Запустите. macOS покажет предупреждение: «Apple не удалось подтвердить, что файл
          „CommaEditor“ не содержит вредоносного ПО». Оно появляется у всех приложений без подписи
          Apple Developer, а у CommaEditor её пока нет. Нажмите «Готово».
        
    3. 
        
  3. 
          Разрешите один раз. На macOS 15 и новее откройте «Системные настройки ▸
          Конфиденциальность и безопасность», нажмите внизу «Все равно открыть» и введите пароль.
          На macOS 14 щёлкните CommaEditor в «Программах» правой кнопкой и дважды выберите «Открыть».
        
    4. 
      

      
Можно обойтись без этого и снять с приложения отметку «скачано из интернета» командой в Терминале:


xattr -dr com.apple.quarantine /Applications/CommaEditor.app

      

        Предпросмотр таблиц по пробелу в Finder заработает после первого запуска CommaEditor.
        Чтобы убедиться, что скачан именно тот файл, выполните
        shasum -a 256 ~/Downloads/CommaEditor-*.dmg и сравните результат с суммой
        на странице выпуска. Приложение работает в песочнице macOS, не выходит в интернет
        и ничего о вас не собирает, подробнее о конфиденциальности.
        Нужна macOS 14 или новее, Apple Silicon или Intel.

Windows, Linux и вторая версия для Mac

      

        Это та же программа с тем же ядром, только интерфейс у неё сделан на Tauri. Установщики
        лежат на странице выпуска рядом с DMG.
        Подписи Microsoft и Apple у них нет, поэтому при первом запуске система попросит
        подтверждение.
      


      
Windows 10 и 11

      
    
        
  1. 
          Скачайте CommaEditor-…-windows-x64-setup.exe. Для ноутбуков на ARM
          (Snapdragon) нужен …-windows-arm64-setup.exe.
        
    2. 
        
  2. 
          Запустите. Windows покажет окно «Система Windows защитила ваш компьютер», как для
          любой программы без платного сертификата. Нажмите «Подробнее», затем «Выполнить
          в любом случае».
        
    3. 
        
  3. 
          Установите. Права администратора не нужны, программа ставится только для вашей
          учётной записи. Если в системе нет WebView2 (в Windows 10 и 11 он обычно уже есть),
          установщик скачает его сам.
        
    4. 
      

      
Проверить файл можно в PowerShell. Сумма должна совпасть с той, что на странице выпуска:


Get-FileHash .\CommaEditor-*-setup.exe


      
Linux

      
AppImage запускается без установки. Пакет .deb подойдёт для Ubuntu и Debian, Flatpak для остальных дистрибутивов:


# AppImage
chmod +x CommaEditor-*-linux-x86_64.AppImage && ./CommaEditor-*-linux-x86_64.AppImage
# Ubuntu 22.04 и новее, Debian 12
sudo apt install ./commaeditor_*_amd64.deb
# Flatpak: среду GNOME он возьмёт с Flathub
flatpak install --user ./CommaEditor-*-linux-x86_64.flatpak
# проверка
sha256sum CommaEditor-* commaeditor_*


      
Две версии для macOS

      

        Для Mac есть две версии: основная, нативная, на AppKit, и CommaEditor W, такая же,
        как на Windows и Linux. Можно поставить обе, у второй на иконке буква W.
      

      
    
        
  • 
          CommaEditor подойдёт, если вы работаете только на Mac. Предпросмотр таблиц
          по пробелу в Finder, автосохранение с версиями, VoiceOver и песочница macOS есть только в ней.
        
    • 
        
  • 
          CommaEditor W пригодится, если хочется ту же программу, что у коллег на Windows
          и Linux. Файл сохраняется только по команде, а после сбоя несохранённые правки
          восстанавливаются. Отметка «скачано из интернета» снимается с неё так:
        
    • 
      


xattr -dr com.apple.quarantine "/Applications/CommaEditor W.app"

      

        Сами себя версии не обновляют. Новую версию берите на странице выпусков, ссылка на неё
        есть в окне «О программе». Рецепты у обеих версий на Mac общие.

Сборка из исходников

      
Нужны Rust 1.88+, Xcode 16+ и XcodeGen.


# тесты ядра
make test
# собрать ядро, сгенерировать проект Xcode и запустить
make run
# проверить, что ваши файлы сохраняются байт в байт
cargo run -p comma-cli -- check ~/Downloads/*.csv

      

        Ядро лежит в core/comma-core, приложение для macOS в apps/macos.
        Версия на Tauri 2 для Windows, Linux и CommaEditor W лежит в apps/desktop:
        make desktop запускает её, make desktop-release собирает установщик.
