Что умеет

      

        
          
ВозможностьЧто именноКлавиши

        
        
          

            1Кодировки и разделители
            UTF-8 с BOM и без, UTF-16, Windows-1251, KOI8-R, KOI8-U, DOS 866, Windows-1250, 1252, 1253, 1254, 1257; запятая, точка с запятой, табуляция, черта. Если определение не уверено — спросит с предпросмотром. Находит и чинит кракозябры вроде «РџСЂРёРІРµС‚».
            
          

          

            2Большие файлы
            Файлы от 64 МБ отображаются с диска, первая страница — за десятые доли секунды. Чтение, поиск, профиль и экспорт идут на всех ядрах, долгие правки — в фоне с отменой.
            
          

          

            3Ремонт файла
            Незакрытые и лишние кавычки, разделитель внутри значения, обрезанные строки. Варианты исправления с превью, «Исправить все» — одним шагом отмены.
            ⌥⌘R
          

          

            4Сортировка, фильтры, поиск
            Сортировка и фильтры — только вид, файл не меняется. Числа вида 1 250,50, даты, естественный порядок. Поиск и замена с регулярными выражениями, в колонке или в выделении.
            ⇧⌘L ⌥⌘F
          

          

            5Профиль колонки
            Тип, пустые и уникальные, минимум, медиана, гистограмма, частые значения. Подсвечивает «n/a» среди чисел и пробелы по краям.
            ⌥⌘P
          

          

            6Вычисляемая колонка
            {price} * 1.2, IF, ROUND, текст и даты — с предпросмотром на первых строках.
            ⌥⌘=
          

          

            7Сравнение двух файлов
            По ключевой колонке или номеру строки, колонки сопоставляются по заголовкам. Миллион строк с миллионом — за 0,17 с.
            ⌥⌘D
          

          

            8Рецепты
            Запишите правки один раз и примените к следующей выгрузке. Рецепт экспортируется в скрипт на pandas, который даёт тот же файл байт в байт.
            
          

          

            9Книги Excel
            .xlsx и .xlsm — правка, при которой остальное в книге не трогается. Формулы пересчитываются сразу, в том числе с именами и ссылками на таблицы (можно по-русски: =СУММ(B2:B5)). Строки вставляются, удаляются, перемещаются и сортируются, а за ними идут ссылки, таблицы, примечания, рисунки, диаграммы и сводные. .xls — просмотр.
            
          

          

            10Экспорт
            JSON, Markdown, HTML, SQL и XLSX — из того, что показано: с учётом сортировки и фильтров. Коды вроде 007 остаются текстом.
            ⇧⌘E
          

          

            11Невидимые символы
            Пробелы по краям ·, табуляция →, неразрывный пробел °, нулевая ширина ¦, перевод строки ↵, пустое ∅.
            ⇧⌘I
          

          

            12Quick Look и карточка записи
            Пробел в Finder показывает таблицу тем же ядром. Широкую строку можно читать и править как форму.
            ⌥⌘I

        Время работы ядра на Apple M4 Pro, файл уже в кэше системы; окно и отрисовка таблицы
        в замер не входят. Таблица из 10 колонок, сортировка по колонке денежных сумм.
        Первый экран одинаков для любого размера: файл от 64 МБ открывается с первыми 32 МБ,
        остальное читается в фоне. Повторить замер: cargo run --release -p comma-cli -- bench.
      

      

        Индекс строк — 16 байт на строку. Прокрутка 12 млн строк — 120 кадров в секунду на
        экране 120 Гц. Книга Excel на 1 млн строк читается на всех ядрах и готова через 0,2 с;
        правка ячейки с пересчётом формул на 100 тыс. строк — десятые доли секунды.
        Приложение весит около 28 МБ.

Как устроено сохранение без лишнего диффа

      

        

          Исходные байты файла остаются в памяти. Документ хранит не таблицу строк,
          а список записей. Нетронутая запись — это диапазон байтов исходного файла.
          Изменённая — список полей, где нетронутые поля по-прежнему ссылаются на исходные
          байты вместе с кавычками, а новые значения хранятся как текст.
        

        

          При сохранении нетронутое копируется побайтово. Новые значения кодируются в
          кодировку файла и берутся в кавычки по правилам этого файла. У каждой записи
          свой перевод строки. Undo и redo — обратимые замены диапазонов записей.
        

      


      

      

        Гарантию «открыл и сохранил без правок — получил тот же файл» проверяют тесты,
        в том числе на 20 000 случайных входов. Книги Excel устроены так же: сохранение
        переписывает только изменённые ячейки, а стили, диаграммы и макросы копируются байт в байт.

Установка

      
    
        
  1. 
          Скачайте DMG со страницы выпуска,
          откройте его и перетащите CommaEditor в «Программы».
        
    2. 
        
  2. 
          Запустите. macOS скажет: «Apple не удалось подтвердить, что файл „CommaEditor“
          не содержит вредоносного ПО». Так она встречает приложения без подписи Apple Developer,
          а CommaEditor пока распространяется без неё. Нажмите «Готово».
        
    3. 
        
  3. 
          Разрешите один раз. На macOS 15 и новее: «Системные настройки ▸
          Конфиденциальность и безопасность», внизу «Все равно открыть», затем пароль.
          На macOS 14: правый щелчок по CommaEditor в «Программах» ▸ «Открыть» ▸ «Открыть».
        
    4. 
      

      
Или одной командой в Терминале — снять отметку «скачано из интернета»:


xattr -dr com.apple.quarantine /Applications/CommaEditor.app

      

        Предпросмотр таблиц по пробелу в Finder заработает после первого запуска CommaEditor.
        Сверить, что файл тот самый: shasum -a 256 ~/Downloads/CommaEditor-*.dmg
        и сравнить с суммой на странице выпуска. Приложение работает в песочнице macOS, не ходит
        в сеть и ничего о вас не собирает — подробнее о конфиденциальности.
        Нужна macOS 14 или новее, Apple Silicon или Intel.

Windows, Linux и вторая версия для Mac

      

        Та же программа на том же ядре, с интерфейсом на Tauri. Установщики лежат на
        странице выпуска рядом с DMG для macOS.
        Подписи Microsoft и Apple у них нет, поэтому системы один раз переспрашивают.
      


      
Windows 10 и 11

      
    
        
  1. 
          Скачайте CommaEditor-…-windows-x64-setup.exe, а для ноутбуков на ARM
          (Snapdragon) — …-windows-arm64-setup.exe.
        
    2. 
        
  2. 
          Запустите. Windows покажет «Система Windows защитила ваш компьютер»: так она
          встречает программы без платного сертификата. Нажмите «Подробнее», затем «Выполнить
          в любом случае».
        
    3. 
        
  3. 
          Установите. Права администратора не нужны: программа ставится только для вас.
          Если в системе нет WebView2 (в Windows 10 и 11 он обычно есть), установщик скачает его.
        
    4. 
      

      
Сверить, что файл тот самый, в PowerShell — и сравнить с суммой на странице выпуска:


Get-FileHash .\CommaEditor-*-setup.exe


      
Linux

      
AppImage работает без установки, .deb — для Ubuntu и Debian, Flatpak — для остальных:


# AppImage
chmod +x CommaEditor-*-linux-x86_64.AppImage && ./CommaEditor-*-linux-x86_64.AppImage
# Ubuntu 22.04 и новее, Debian 12
sudo apt install ./commaeditor_*_amd64.deb
# Flatpak: среду GNOME он возьмёт с Flathub
flatpak install --user ./CommaEditor-*-linux-x86_64.flatpak
# проверка
sha256sum CommaEditor-* commaeditor_*


      
Две версии для macOS

      

        На Mac есть основная, нативная версия на AppKit, и CommaEditor W — та же, что на
        Windows и Linux. Они ставятся рядом; у второй на иконке буква W.
      

      
    
        
  • 
          CommaEditor — берите её, если работаете только на Mac. Только у неё предпросмотр
          таблиц по пробелу в Finder, автосохранение с версиями, VoiceOver и песочница macOS.
        
    • 
        
  • 
          CommaEditor W — если хотите на Mac ту же программу, что у коллег на Windows и
          Linux. Сохранение явное, после сбоя несохранённые правки восстанавливаются. Снять
          отметку «скачано из интернета» для неё:
        
    • 
      


xattr -dr com.apple.quarantine "/Applications/CommaEditor W.app"

      

        Обновляться автоматически ни одна версия не умеет: новая версия — на странице выпуска,
        ссылка на неё есть в окне «О программе». Рецепты у двух версий на Mac общие.

Сборка из исходников

      
Нужны Rust 1.88+, Xcode 16+ и XcodeGen.


# тесты ядра
make test
# собрать ядро, сгенерировать проект Xcode и запустить
make run
# проверить побайтовый round-trip своих файлов
cargo run -p comma-cli -- check ~/Downloads/*.csv

      

        Ядро — core/comma-core, приложение для macOS — apps/macos,
        для Windows, Linux и CommaEditor W — apps/desktop на Tauri 2
        (make desktop запускает его, make desktop-release собирает установщик).
